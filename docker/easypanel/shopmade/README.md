# Easypanel template

The Shopmade template for [easypanel-io/templates](https://github.com/easypanel-io/templates). To submit it, copy this
folder to `templates/shopmade/` in a fork of that repo, run `npm run build`, and open a PR. `assets/logo.png` is the
shopmade.pro app icon; the screenshots are the starter site and the website editor of a fresh v0.1.0 install. The editor shot was taken
with the optional jobs and CRM packages installed, so its sidebar also shows Jobs, Schedule and Contacts.

Bump `appServiceImage` in `meta.yaml` to the newest `ghcr.io/labskai/shopmade-core` tag and add a `changeLog` entry
whenever you update it there.
